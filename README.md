# 坏文件生成器（Bad File Generator）

一个**纯前端、零依赖、离线可用**的网页小工具，核心功能只有一个：**创建“打不开的文件”**。你可以在浏览器里生成图片、视频、音频、Office 文档、压缩包、程序文件……等任意格式的文件，但内容是随机字节或无效数据，结构被彻底破坏，因此任何软件打开时都会提示“文件损坏 / 无法解析 / 格式无效”。

- 纯前端单文件实现，双击 `index.html` 即可离线使用
- 无网络请求、无后端、无第三方依赖
- 海量扩展名预设，也可自定义后缀
- 任意大小（无上限），支持 B / KB / MB / GB / TB / PB
- 支持批量生成（自动补零序号，逐个下载）
- Mac / PC 现代浏览器 100% 兼容

## 功能特性

- **生成设置**：自定义文件名、数量（最多 100 个）、扩展名、文件大小
- **扩展名预设**：内置 10 大类、百余种常见扩展名
  - 文档：txt、pdf、doc、docx、xls、xlsx、ppt、pptx、wps、odt、md、epub…
  - 图片：jpg、png、gif、webp、bmp、psd、heic、tiff、svg、raw…
  - 音频：mp3、wav、flac、aac、ogg、m4a、wma…
  - 视频：mp4、mkv、avi、mov、wmv、webm、flv…
  - 压缩与镜像：zip、rar、7z、tar、gz、iso、dmg、bin…
  - 程序与系统：exe、dll、so、apk、deb、msi、pyc、elf…
  - 数据库：sql、db、sqlite、bak…
  - 代码与文本：json、xml、py、js、ts、go、java、sh…
  - 字体：ttf、otf、woff、woff2…
  - 其他：pem、key、torrent、m3u8、dat、enc…
- **随机填充模式**：使用 `crypto.getRandomValues` 生成随机字节（不兼容时自动降级为伪随机填充）
- **批量下载**：数量大于 1 时自动生成带三位序号的文件（`bad-file_001.pdf`、`bad-file_002.pdf`…），逐个下载，无需手动改名
- **进度显示**：实时显示写入进度、速度、预计剩余时间与已完成数量
- **流式写入**：Chromium 系浏览器使用流式分块（64MB/块），1GB 到 1TB 都不会先占满内存

## 使用方法

1. 用浏览器打开 `index.html`（推荐 Chrome / Edge / Safari / Firefox）。
2. 填写文件名（不含扩展名）、数量、扩展名（或勾选“使用自定义扩展名”）。
3. 设置文件大小，可点击下方快捷按钮快速选择（1 MB、50 MB、1 GB、20 GB 等）。
4. 点击「开始生成并下载」，等待进度条走完，文件即会出现在下载目录。

> 批量生成时，个别浏览器（如 Safari / Firefox）不支持目录选择器，会逐个弹窗保存，请逐一点击确认。

## 为什么这些文件打不开？

任何文件（图片、视频、文档、压缩包等）都需要合法的“文件头 + 数据结构”才能被软件识别。本工具向文件中填充随机字节或无效内容，破坏了文件结构，因此所有软件打开都会报错。生成的文件大小、扩展名与内容无关，文件头完全无效。

## 兼容性说明

| 浏览器 | 生成方式 | 说明 |
| --- | --- | --- |
| Chrome / Edge（Chromium） | 流式写入 | 1GB–1TB 不先占满内存，边生成边落盘 |
| Safari / Firefox | 内存模式 | 中小文件无压力，超大文件请留意内存 |
| 任意现代浏览器 | 自动降级 | 不支持流式写入时自动切换为内存模式 |

## 使用场景

- 测试下载站、校验服务、断点续传、文件监控对异常文件的容错能力
- 测试安全软件 / 病毒扫描对损坏样本的响应
- 前端开发、日志分析、教学演示（文件格式与 MIME 嗅探）

## 技术实现

- 单文件后端：原生 HTML + CSS + JavaScript，无任何框架与依赖
- 随机数据：`crypto.getRandomValues()`（弱环境自动降级为 xorshift 伪随机 / 文本填充）
- 流式写入：`File System` API（`showSaveFilePicker` / `showDirectoryPicker`），逐块（64MB）写入，避免内存峰值
- 内存降级：不支持 File System API 时，拼接为 `Blob` 后通过临时 URL 触发下载
