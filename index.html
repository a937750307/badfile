坏文件

核心功能只有一个：创建**打不开的文件**。随机填充、结构破坏，图片/视频/文档/压缩包一律无法打开。
海量扩展名 · 任意大小 · 无上限 · Mac / PC 浏览器 100% 兼容。

说明

为什么这些文件打不开？

任何文件（图片、视频、Office 文档、压缩包……）都需要合法的“文件头 + 数据结构”才能被软件识别。本工具往文件里填充随机字节或无效内容，结构被彻底破坏，因此用任何软件打开都会提示“文件损坏 / 无法解析 / 格式无效”。

兼容性。

  • Mac / PC / 现代浏览器直接可用（Chrome、Edge、Safari、Firefox），纯前端、零网络请求、双击 html 即离线使用。
  • Chromium 系使用流式写入：1GB 到 1TB 都不会先占满内存，边生成边落盘。
  • Safari / Firefox 自动降级为内存模式，中小文件无压力；超大文件请留意内存。
  • 批量：数量大于 1 时按序号逐个下载（bad-file_001.pdf、bad-file_002.pdf…），自动补零，无需手动改名。

使用场景

  • 测试下载站、校验服务、断点续传、文件监控对异常文件的容错能力
  • 测试安全软件 / 病毒扫描对损坏样本的响应
  • 前端开发、日志分析、教学演示（文件格式与 MIME 嗅探）
